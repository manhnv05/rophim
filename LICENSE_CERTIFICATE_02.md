# Giấy phép/Chứng chỉ 02 – Sử dụng API (API Usage License)

Tài liệu song ngữ Việt/Anh xác định điều khoản sử dụng các điểm cuối API và dữ liệu do Rophim cung cấp.

## Phạm vi áp dụng / Scope
- VN: Áp dụng cho lập trình viên tích hợp API Rophim được cấp khoá truy cập hợp lệ.
- EN: Applies to developers integrating Rophim APIs with valid access credentials.

## Quyền sử dụng / Permitted Use
- VN: Gọi API trong giới hạn tốc độ được công bố; chỉ dùng cho mục đích hợp pháp và minh bạch với người dùng cuối.
- EN: Call APIs within published rate limits; use only for lawful purposes with transparent end-user communication.

## Hạn chế / Restrictions
- VN: Cấm thu thập trái phép dữ liệu cá nhân, đảo ngược mã, tấn công từ chối dịch vụ, hoặc chia sẻ khoá truy cập cho bên thứ ba.
- EN: Unauthorized personal data harvesting, reverse engineering, denial-of-service attempts, or sharing credentials with third parties are prohibited.

## Nghĩa vụ bảo mật / Security
- VN: Bảo vệ khoá API, mã hóa kênh truyền, xoay khoá khi có nghi ngờ lộ lọt.
- EN: Protect API keys, encrypt transport, and rotate keys upon suspected compromise.

## Hiệu lực / Validity
- VN: Hiệu lực đến khi bị thu hồi hoặc thay thế; Rophim có quyền tạm ngưng nếu vi phạm.
- EN: Remains valid until revoked or replaced; Rophim may suspend access upon violations.

## Liên hệ / Contact
- VN: Liên hệ đội ngũ hỗ trợ kỹ thuật qua kênh chính thức để được cấp/thu hồi khoá.
- EN: Contact the official technical support channel for key issuance or revocation assistance.
